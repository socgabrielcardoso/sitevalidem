# ValideM

Laboratório de Application Security focado em **business logic**, fronteiras de confiança e manipulação de dados controlados pelo cliente.

## Objetivo
Demonstrar, com cenários sintéticos e seguros, por que preço, desconto, quantidade, permissões e outros valores críticos precisam ser validados por uma fonte autoritativa no backend.

## Áreas
- AppSec
- API Security
- Business Logic Security
- Trust Boundaries
- HAR/JSON Analysis
- Security Evidence
- Secure Validation

O projeto é educacional e local. Não deve ser usado para testar aplicações de terceiros sem autorização.
