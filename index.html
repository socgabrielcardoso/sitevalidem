Arquitetura de pagamento

  1. 1
    Cliente escolhe

    Envia somente identificador, quantidade e dados estritamente necessários.

  2. 2
    API valida o contrato

    Rejeita campos inesperados e tipos inválidos.

  3. 3
    Servidor recalcula

    Busca preço e regras comerciais no catálogo confiável.

  4. 4
    Servidor cria a cobrança

    Gera a transação com o valor recalculado.

  5. 5
    Confirmação é reconciliada

    Webhook autenticado e consulta server to server confirmam valor, pedido e status.
