# Authoritative Data

Uma fonte autoritativa é a origem confiável usada para tomar decisão de negócio.

Exemplos:
- catálogo server-side para preço;
- banco para propriedade do objeto;
- diretório para papel de acesso;
- serviço de inventário para disponibilidade.

O cliente pode sugerir valores, mas não deve defini-los unilateralmente.
